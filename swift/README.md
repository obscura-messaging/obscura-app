# ObscuraKit (Swift)

Swift package for the iOS application bridge. Shared behavior and the kit
contract live in [`docs/KIT_API.md`](../docs/KIT_API.md).

## Build and test

Requires macOS and Xcode 16+. SQLCipher depends on CommonCrypto; Linux is not
supported. The package targets iOS 16 and macOS 13.

From the repository root:

```bash
just swift-build
just swift-unit
just swift-integration http://localhost:3000
```

After libsignal has been bootstrapped, from `swift/`:

```bash
./dev.sh build
./dev.sh test --filter UnitTests
./dev.sh test --filter UnitTests.ObservationTests
OBSCURA_TEST_API=http://localhost:3000 ./dev.sh test --filter ScenarioTests
```

`dev.sh` selects Xcode's Swift toolchain and sets `LIBRARY_PATH` for the
libsignal FFI. `scripts/bootstrap-libsignal.sh host` prepares the pinned
libsignal v0.40.0 dependency. Do not change that pin without coordinating
server key support. Protobuf bindings in `Sources/ObscuraKit/Proto/` are
generated by `scripts/gen-proto.sh`.

Unit tests are offline. Scenario tests require a server and default to
`http://localhost:3000`; use `OBSCURA_TEST_API` to select a test
server. See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for server setup.

`ScenarioTests.ServerContractTests` uses the same server configuration as the
existing integration job. It exercises gateway-driven repeated refill, delayed
signed-key bootstrap, token rotation during attachment/push/refill operations,
device removal, batch rejection, metadata/session prekey cost, and local SQLite
inbox/friend-write faults followed by real gateway redelivery. No admin/database server access
or additional environment switches are required.

The receive path passes its GRDB transaction through libsignal's `StoreContext`;
store callbacks use that connection instead of re-entering the database queue.

## Host integration

The host supplies `SessionStorage`, `ObscuraLogger`, and a device name.
There is no public in-memory constructor or default storage/logger.

```swift
let client = try ObscuraClient(
    apiURL: apiURL,
    dataDirectory: directory,
    userId: databaseUserId,
    keychainAccessGroup: accessGroup,
    deviceName: deviceName,
    sessionStorage: storage,
    logger: logger
)

let restored = await client.restorePersistedSession()
let scenario = try await client.login(username, password)
try await client.register(username, password)
try await client.resetAccount(username, password)
let request = try await client.beginLink(username, password, deviceName: deviceName)
try await client.completeLink(request)
try await client.approveLink(request.code)
let devices = try await client.devices()
try await client.unlinkDevice(deviceId)
let isPrimary = try await client.isPrimary
try await client.connect()
await client.disconnect()
try await client.logout()
try await client.wipeDevice()

let userId = await client.userId
let deviceId = await client.deviceId
let username = await client.username

let report = try await client.send(
    to: recipientUserIds, modelKey: modelKey, entryId: entryId,
    sentAt: timestamp, payload: bytes
)
let rows = try await client.inbox.peek(limit: 50)
try await client.inbox.consume(rowIds)
try await client.inbox.discard(rowIds, reason: reason)
let depth = try await client.inbox.depth()
try await client.entries.put(model: modelKey, entry: StoredEntry(
    id: entryId, data: opaqueString, sentAt: timestamp,
    authorUserId: authorUserId, authorDeviceId: authorDeviceId, localMetadata: metadata
))
let entries = try await client.entries.get(model: modelKey, ids: entryIds)
let all = try await client.entries.all(model: modelKey)
try await client.entries.erase(model: modelKey, ids: entryIds)

try await client.addFriendByCode(code)
try await client.acceptFriend(friendUserId)
try await client.removeFriend(friendUserId)
let friends = try await client.getFriends()
let code = try await client.friendCode()
try await client.sendTyping(to: recipientUserIds, contextId: contextId, state: .started)

let attachment = try await client.uploadAttachment(plaintext)
let plaintext = try await client.downloadDecryptedAttachment(
    id: attachment.id, contentKey: attachment.contentKey, nonce: attachment.nonce
)
try await client.registerPushToken(pushToken)
```

`SessionStorage` is `AnyObject, Sendable` and has three throwing methods:

```swift
func save(_ session: [String: String]) throws
func load() throws -> [String: String]?
func clear() throws
```

The dictionary keys are `token`, `refreshToken`, `expiresAt`, `userId`, `deviceId`, and
`username`. The host must implement durable storage. Session storage failures
surface as `ObscuraError.storageFailed`, code `STORAGE_ERROR`;
`restorePersistedSession()` reports failures through the logger and returns
`false` instead of throwing.

The file-backed constructor writes SQLCipher-encrypted `obscura.sqlite` under
`dataDirectory`. Its per-user key is held in the Keychain, optionally shared
through `keychainAccessGroup`; file protection is
`completeUntilFirstUserAuthentication`.

## Observation

```swift
let authState = client.authState
let connectionState = client.connectionState
for await state in client.observeAuthState() { }
for await state in client.observeConnectionState() { }
for await _ in client.observeFriendsChanged() { }
for await userIds in client.observeTyping(contextId: contextId) { }
for await modelKey in client.messageReceived { }
let lines = client.getDebugLog()
```

Observation methods and current auth/connection state are nonisolated.
`messageReceived` is a single-consumer `AsyncStream<String>` buffered to the
newest 100 model keys. `getDebugLog()` returns the newest 200 lines first.
Friend observation uses GRDB `ValueObservation`; state and typing observations
use ordered `AsyncStream` publication. The kit does not depend on Combine.

## Source map

| Path under `Sources/ObscuraKit/` | Role |
|---|---|
| `ObscuraClient*.swift` | Actor facade, lifecycle, receive and send |
| `Network/` | REST and gateway WebSocket |
| `Messaging/` | Signal sessions and per-device submission |
| `Stores/` | Inbox, entries, friends and device directory |
| `Storage/` | Pre-release database schema and wipe |
| `Crypto/` | Signal records, attachments and database key |
| `Wire/` | Encoding, UUID conversion and typing state |

No Notification Service Extension is supplied. See
[`docs/NSE_PREREQUISITES.md`](docs/NSE_PREREQUISITES.md) for platform integration
prerequisites.
